# Added Libraries

## React-Query : [check it out](https://tanstack.com/query/latest/docs/framework/react/overview)

If I had a dollar everytime this has been mentioned as the goto/industry standard. It is fairly straightforward to set up. Can remove if incorporating Redux and RTKQuery. 

## Zod : [check it out](https://github.com/colinhacks/zod)

Already using typescript, Zod is a great validation library to compliment type saftey with schema validation, so we can confidently use data properties. 

## Tailwind [check it out](https://tailwindcss.com/): 

The css library i've been using lately.

## Immer and use-immer: [check it out](https://immerjs.github.io/immer/example-setstate)

Used for making our state immutable. I used to use Immutable JS, this works better with react state and hooks in my opinion. This is especially usefull for deeply nested state.
